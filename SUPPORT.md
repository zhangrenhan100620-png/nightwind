# Support

Nightwind is maintained on a best-effort basis.

- Use the bug report template for reproducible incorrect behavior.
- Use the feature request template for new checks or output formats.
- Include your operating system, Python version, Nightwind version, command, and sanitized output.
- Search existing issues before opening a new one.
- Never include access tokens, private repository content, personal data, or vulnerability details.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
